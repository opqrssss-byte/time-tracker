NotebookLM 同步 · 一次性配置引导

配一次，永久生效。之后你的时间记录会自动流进 Google Doc，NotebookLM 挂载该文档后即可在对话中引用你的真实时间数据。全程约 10 分钟。

1创建 Google Cloud 项目并启用 API

  1. 打开 Google Cloud Console，登录你的 Google 账号
  2. 顶部项目选择器 → 新建项目，名字随意（如 time-tracker）
  3. 左侧菜单 → API 和服务 → 库，搜索并分别启用：Google Docs API 和 Google Drive API

2创建服务账号并下载密钥

  1. 左侧菜单 → API 和服务 → 凭据 → 顶部 创建凭据 → 服务账号
  2. 名称随意（如 docs-sync），直接点完成（角色可以不选）
  3. 点进刚建的服务账号 → 密钥 标签页 → 添加密钥 → 创建新密钥 → JSON，会下载一个 .json 文件
  4. 记下服务账号的邮箱地址，形如 docs-sync@xxx.iam.gserviceaccount.com
这个 JSON 文件相当于密码：不要分享、不要上传到任何地方。本工具只把它保存在你自己电脑的浏览器/桌面组件本地存储里。

3创建《时间日志》文档并授权

  1. 打开 docs.new 新建一个 Google 文档，标题改为 时间日志（名字随意）
  2. 点右上角 共享，把第 2 步的服务账号邮箱加为编辑者
  3. 复制文档链接中 /d/ 和 /edit 之间的那串 ID

4把文档挂进 NotebookLM

  1. 打开你的 NotebookLM 个人笔记本
  2. 添加来源（Source）→ 选择 Google 文档 → 选中刚建的《时间日志》
  3. 以后文档内容更新时，NotebookLM 会提示来源已更新，点一下刷新即可吸收最新时间数据

5回到时间追踪，填入配置

  1. 回到 时间追踪 → 设置 → NotebookLM 同步
  2. 粘贴第 3 步的 Doc ID 和第 2 步下载的 JSON 密钥全文
  3. 点 保存配置——看到「已同步」即全部打通 🎉
如果提示网络错误：访问 Google API 需要你的代理/魔法环境处于开启状态（和你平时用 Gemini 一样的网络条件）。
