# 桌面组件「弧排切换」· 问题简报

> 用途：给外部产品/动效设计看的自包含说明。
> 同时附上**我们已经试过的 6 个版本和各自的失败原因**，避免重复劳动。
> 最后更新：2026-10-12 夜

---

## 一、这是什么

一个常驻桌面的时间追踪组件（Electron 透明窗口，约 260×380）。
窗口正中是一个 **152px 的圆形表盘**，盘内显示当前状态。

**滚轮 = 表冠**：转一下，分类沿弧排列滑过，落在弧心的那个放大、显示名字与今日时长。
参考对象（用户指定）：**三星手表的列表**、**早期苹果手表的应用列表**（中心放大、边缘缩小、最外模糊）、
以及健康/运动类表盘应用里"**贴着表盘边缘展示选项**"的做法。

## 二、当前形态（已实现，可运行）

- **只显示 5 条**（选中 + 上下各 2）
- **选中最大、向两端三级递减**：高 30 / 24 / 18，字号同步递减
- **选中 + 上下各一个显示名字与时长**（如「工作 2:15」）；更外两条**只有颜色 + 1.2px 模糊**
- 一列，左端**贴着盘缘**，整列随圆边弯曲
- 滚轮步进：慢滚一格一格；快滚按累积量跨多步（上限 4）
- 停留 900ms 自动确认（切到该分类）；滚到末位「新增项目」停留则弹出新增窗口

**可直接体验**：`site/lab-arc.html`（自包含单文件，无依赖无后端，浏览器打开即可滚）

## 三、用户的核心诉求（原话）

> "让荧光条的颜色填满，**左侧随圆环形变**"
> "看起来就是**左侧被切了一块贴在圆环上了**，根本没随着滚轮滚动而形变"
> "中心的那个会放大、边缘的会缩小，最边缘的会模糊"

即：**滚动时，条的形状要看得出来在跟着圆边变化**，而不是静态地"贴"上去。

## 四、★ 一个必须先知道的几何事实

用户坚持这种效果"一定可以"（三星/苹果手表做到了）。**用户是对的**，但有一个边界：

**"左边界弯 + 右边界也弯 + 还要横向装下文字" —— 这三件事在 152px 的盘上不能同时成立。**

推导：
- 左边界 = 盘缘弧（半径 72）
- 右边界若也用同心弧，其半径 = 72 − 条宽（约 64）≈ **8**
- **半径 8 的弧在 30px 高度上退化成一条直线** → 右边看不出弯
- 若把条变窄让内弧半径变大（比如内弧 40）→ 条只剩 32px 宽 → **装不下「工作 2:15」**

**结论**：在这个尺寸下，"形状被掰弯"的幅度上限是 **1~3px**（视觉不可辨）；
手表上那种"形变感"，实际来自 **位置 + 尺寸随距离的连续变化**，不是形状弯曲。

**如果一定要"形状明显弯"**，必须动一个尺寸：

| 办法 | 改什么 | 代价 |
|---|---|---|
| A | 条大幅加高（18→45） | 一屏只剩 2~3 条 |
| B | 盘改小（152→100 左右） | 整体变小 |
| C | 条沿弧走（轴线也弯） | 文字需斜排，可读性下降 |
| D | 盘做大（152→190+） | 组件占桌面更多 |

## 五、已试过的 6 个版本（请勿重复）

| 版本 | 做法 | 结果 |
|---|---|---|
| v1–v2 | 圆点弧排 → 荧光条 | 太小、太简陋 |
| v3 | 一列随圆边弯曲 | 形状对，但没聚焦层次 |
| v4 | 5 条聚焦窗 + 模糊分级 | 层次对了 |
| v5 | 加大撑满 + 时长入条 | 尺寸对了；发现"左端按中心 y 定位"会把宽度挤没（几何 bug） |
| **v6** | **左端伸到圆外、靠圆形裁切塑形** | ✗ **失败**：视觉变成"从左侧显示范围外面弹出来" |
| v8 | 左边界直接画成盘缘弧（SVG path） | ✓ 新月空隙被填满，但右边仍是直线 → 用户说"像切了一块贴上去" |
| v9–v10 | 元素复用恢复动效 + 修正渲染崩溃 | 可运行；**"形状弯曲"仍未达用户预期** |

## 六、想请教的问题

1. **手表上那种"贴着边缘滚动"的形变感，本质是什么？** ——是位置/尺寸的连续变化，还是真有形状弯曲？（我们的推导指向前者，但用户观感上认为后者——请判断谁对）
2. 若确实需要"形状明显弯"，**上面 A/B/C/D 哪条路对产品伤害最小**？
3. 有没有**第 5 种**我们没想到的做法（在 152px、一屏 5 条、文字横排这三个约束下）？

## 七、技术约束（供参考）

- 表盘 152px，盘内可用半径约 72px
- 5 条要"撑满"（实测占盘高 130/154）
- 文字必须横排可读，且**不许超出条的范围**（超出用省略号）
- 一切形状**不得超出圆盘**（硬要求）
- 三端共用同一套几何（桌面组件 / 网页 / 微信小程序）
- 实现栈：纯 HTML + SVG + 原生 JS（无框架），文件为 `site/lab-arc.html`
