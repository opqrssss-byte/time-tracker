为什么这版要按"小组件"重做

你说它将来要放手机桌面、和别的小组件并排——那判断标准就变了： 上一版的卡片 + 发丝描边 + 细荧光条是"屏幕内 UI"的语言。 缩到小组件尺寸后，1px 描边会直接消失，细条会细成一根头发，整个东西就散架了。

桌面小组件要的是大色块、粗字、少细节。所以这版：每一行本身就是那条荧光条， 文字嵌在条内部，所有描边全部去掉。

摆在一起是什么样

这版改了什么

  • 整行即荧光条：条高 58（选中 68），圆角全圆， 文字（名称 + 时长）嵌在条内
  • 条长 = 今日时长（按当日最大值归一）；短到装不下文字时， 以"刚好装下文字"为下限，不会出现半个字
  • 去掉全部描边：没有卡片、没有发丝线、没有选中框。层次只靠 色块 + 柔和辉光 + 尺寸差
  • 选中行靠"变大变亮"：名称 19→24、条 58→68、 未选行整条降到 .5 透明度——不再需要一条高亮带
  • 字色跟条色走：亮色条（如琥珀）自动用深字，暗色条用白字， 否则白字压在亮黄上根本看不清
  • 末尾「新增」：一条没有颜色的空条，排在列表最后， 滑到底选中它、松手即打开新增面板

视觉规格（375 宽基准）

  • 行距 76，条最大宽 335，条内左右内距 18/20
  • 辉光：0 0 22px 色·45%（散光）+ 0 0 6px 色·70%（贴边）。 只有一层会像实心色块，没有"荧光"感
  • 未选行整条 opacity .5；再远的行 .5→.26→0 逐级淡出
  • 「新增」条：rgba(255,255,255,.05) 底、灰字、与第一条同宽
  • 列表进出场 200ms：淡入 + 0.95→1 放大；环彻底退场 （不保留半透明，否则大色块和一个幽灵环叠着会显脏）
