# 矢量知识图谱工作簿 · 使用与编辑指南

> 面向：任何一台机器上打开这套图的人（包括回家继续编辑的你）
> 更新时间：2026-10-30 · 配套脚本 `build_workbook.py`

## 这是什么

`00-知识图谱画布.vectorcraft` 是一个 **VectorCraft 工程文件**，单文件装 5 个画板（就是 5 个"页面"）。里面是「怎么画知识图谱」的一套讲解图，加两张留给你自己画的白纸。

同目录另外两样东西是它的**投影**，不是别的文件：

| 文件 | 用途 |
|---|---|
| `00-知识图谱画布.vectorcraft` | **可编辑原件**，用 VectorCraft 打开 |
| `00-总览-0X-*.png` | 每个画板一张图，手机 / GitHub / 微信里看这个 |
| `00-知识图谱画布.pdf` | 5 页，打印或丢给多模态模型识图 |
| `build_workbook.py` | 生成脚本，能重建上面全部 |

## 怎么拿到这些文件

在任意一台机器上：

```bash
git clone https://github.com/opqrssss-byte/time-tracker.git
cd time-tracker/design/vector
```

不想装 git 就在 GitHub 页面里直接下载：打开 `design/vector/`，点 `00-知识图谱画布.vectorcraft` → 右上角 Download raw file。

只为了看一眼图的话，不用下载 `.vectorcraft`，看同目录的 PNG 就够了。

## 回家第一件事：打开它

**1. 装 VectorCraft 0.18.0** —— <https://getartcraft.com>（开源、免费，Rust + WASM，约 172MB）
装的时候如果默认路径 `Program Files` 装不进去，装到 `LocalAppData\Programs\ArtCraft\VectorCraft` 也完全可以，**但千万别用启动器**（见下）。

**2. 别点启动器。** `ArtCraft Launcher` 有必现 bug，点「开启」会报 *"X isn't where it was installed"*。原因是启动器不记录安装路径。**卸载重装也没用。**

正确开法：

```
%LOCALAPPDATA%\Programs\ArtCraft\VectorCraft\vectorcraft.exe
```

双击它，或者在命令行里把 `.vectorcraft` 路径当参数传进去。

**3. 打开后按 `Ctrl+-` 缩到 35% 左右，才能一屏看全 5 个画板。** 默认 109% 缩放下窗口只装得下一个画板，很容易误以为"文件里只有一两页"。

## 5 个画板

排成两排，横着走：

| 画板 | 位置 | 内容 |
|---|---|---|
| 01-四种连线 | 上排左 | 2×2 卡片：定层级 / 连路径 / 标互斥 / 标平替 |
| 02-你画我改闭环 | 上排中 | 四步流程 + 正反认知对照 |
| 03-工具库 | 上排右 | **零件箱**：6 种节点 / 8 种连线 / 9 个算子 / 3 种容器 / 9 个语义色 |
| 04-空白画布 01 | 下排左 | 四象限引导版，四个区块已预置标题 |
| 05-空白画布 02 | 下排右 | 纯净版，只有边缘刻度 |

**你的用法**：在 03 里点一个零件 → `Ctrl+C` → 切到 04 或 05 → `Ctrl+V`。

## 编组和锁定：什么能拖，什么拖不动

**33 个组** —— 一个语义单元一组。拖动时整组跟着走：

- 01 的四张 Bento 卡（每张 16–21 个对象）
- 02 的四张流程卡、回环箭头、两张对照卡
- 03 的每个节点、每个容器、每个算子、每个色板条目
- 04 的中心锚点框

要改组里单个元素：**双击进组**，改完 `Esc` 退出。

**65 个锁定对象** —— 选不中、拖不动，防止误操作散架：

- 5 张画板白底
- 各画板的大标题和副标题
- 03 的分类标签（节点 / 连线 / 算子与角标 / 容器）和 4 条分隔线
- 04 的十字虚线和四象限标题
- 05 的全部边缘刻度

**想让某块能拖**：菜单 `Object > Unlock All`（或 `Ctrl+Alt+2`）解锁全部，再单独拖。改完记得重新锁。

## 改内容：两条路，必须选一条

这是最容易踩的坑，**先说清楚**：

### 路 A：改脚本，重跑（推荐）

```bash
python design/vector/build_workbook.py
```

改 `build_workbook.py` 里的坐标和文案 → 重跑 → `.vectorcraft` / PNG / PDF 全部重建。

**优点**：一切可重建，改错了改回来就行。
**代价**：**你在软件里手动拖的每一个位置、改的每一处样式，全部被覆盖。**

### 路 B：在软件里手改

直接在 VectorCraft 里拖、改、加。改完 `Ctrl+S`。

**优点**：所见即所得，随手就改。
**代价**：**这份文件从此不能被脚本覆盖**。一旦重跑 `build_workbook.py`，手改全部消失。

**所以：手改之前先想清楚——这个改动是"一次性的"还是"以后还要重建"。** 后者请改脚本。

## 字体：别换回 Source Sans 3

全篇统一 `Noto Sans SC`。

**为什么强调**：文件里如果写 `Source Sans 3`（VectorCraft 的默认字体），它在 Windows 上**没有中文字形**，会回退到**宋体**。整份稿子会变成衬线体，横细竖粗、三角形笔锋，完全不是苹果那种风格。这个坑踩过一次，改回来花了一轮。

也不要用 `Microsoft YaHei UI`：宽度只多 3.9% 看着更安全，但笔画方硬、字面偏小，离苹方更远。

## 想加东西时注意尺寸

- 画板统一 **900×620**，最底层垫一张纯白矩形（画板自身的背景色不参与导出）
- 内容区右边界：01 / 02 / 04 / 05 用 `x: 60..840`；03 的零件区 `x: 60..666`，右侧色板 `x: 700..840`
- 苹果系统色：`#007AFF` 蓝 / `#34C759` 绿 / `#FF9500` 橙 / `#FF3B30` 红 / `#AF52DE` 紫；中性走 iOS 灰阶 `#1D1D1F` → `#AEAEB2` → `#E5E5EA`

## 几个会浪费时间的坑

**① `cmd start` 启动的进程几秒就没了。** 用命令行启动 VectorCraft 时不要经 `cmd /c start`，会被环境回收，表现为"进程起来一下又消失"，让人误判成文件打不开。直接执行 exe 即可。

**② 强杀进程会留下恢复快照，下次打开加载的是旧版本。** 窗口标题出现 `*xxx [Recovered] — VectorCraft` 就说明你正在看残影，不是磁盘上的文件。清理方法：退出应用后删掉

```
%APPDATA%\VectorCraft\Data Recovery\<数字id>\
```

再重开。（删之前先备份。）

**③ 判断"文件是不是真的、是不是新的"，别看窗口，看这三样**：

- `vectorcraft-cli info <文件>` 报的画板数
- 窗口标题有没有 `[Recovered]`
- 文件大小和修改时间对不对得上

**④ 画板背景色不参与导出。** `artboard.new {color}` 只影响屏幕，导出的 PNG/PDF 是透明的。要底色就在最底层画矩形（脚本一直这么干）。

**⑤ 箭头有原生端点，不要用三角形拼。** `stroke.set` 支持 `endArrow`（`Arrow` / `DoubleArrow` / `Bar` / `CircleOpen` 等四十多种）和 `arrowAlign: "tip"`。拼出来的箭头是两个对象，一拉长就散。
