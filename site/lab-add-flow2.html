新增项目 · 更简洁的流程 · 3 个方案（试用：打字 / 滚轮 / 点 +）

S1 · 打字即建弧排打开就直接打字：实时过滤分类
没有匹配 → 回车 = 新建（自动色）
顺带把"分类多找不到"也解决了
S2 · 顺着滚滚到「＋新增分类」就直接打字
回车即建；有字时滚轮改颜色
不换屏、没有按钮
S3 · 一键直达盘底 + 常驻（计时中也在）：点 → 打字 → 回车
颜色自动配好；想改再点开色环
保守基线：入口明确、零惊喜
共同的三处：① 颜色自动分配未用色（选色降为可选）；② 进入即接键盘（修掉"还得先点一下输入框"）； ③ 回车即建、Esc 取消（不需要"确定"按钮）。
Demo 是真的：S1 能打字（中文输入法可用）、S2 能滚轮滚动并在末行就地输入、S3 能点 + 走完整流程。
